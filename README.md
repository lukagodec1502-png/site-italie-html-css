# 🍕 Site Vitrine - Découverte de l'Italie

Ce dépôt contient le code source d'un site web vitrine dédié à la culture, l'histoire et au tourisme en Italie. Ce projet collaboratif a été réalisé dans le cadre de ma première année de BUT Informatique à l'IUT de Lannion.

## 🎯 Description du Projet
L'objectif de ce projet web était de concevoir un site interactif, esthétique et totalement "responsive" (adaptable sur mobile) en utilisant exclusivement HTML5 et CSS3, sans aucun recours à JavaScript[cite: 3, 10]. Le site permet aux utilisateurs d'explorer la richesse italienne à travers trois grandes catégories : les Lieux incontournables (le Colisée), les Chefs-d'œuvre (La Joconde) et les Personnages célèbres (Jules César)[cite: 3, 5, 7, 9].

## 🛠️ Technologies Utilisées
* **Langages :** HTML5, CSS3
* **Outils :** Git & GitHub (pour le travail collaboratif), polices Google Fonts (Inter, Bodoni Moda)[cite: 3]

## 🚀 Fonctionnalités Techniques Remarquables
* **Navigation 100% CSS :** Le menu dynamique de la page d'accueil fonctionne grâce à une logique technique utilisant des boutons radio invisibles (`<input type="radio" hidden>`) associés au sélecteur CSS `:checked` pour faire apparaître les différentes rubriques[cite: 3, 10].
* **Design Fluide et Multimédia :** Intégration d'une vidéo en boucle en arrière-plan (`autoplay muted loop`) pour un rendu immersif dès l'en-tête[cite: 3], complétée par des animations d'apparition fluide (`@keyframes`) et des effets de survol sur les cartes[cite: 6, 10].
* **Responsive Design :** Utilisation avancée des *Media Queries* (`@media screen and (max-width: 768px)`) pour repenser l'affichage sur smartphone : transformation des grilles en colonnes simples, adaptation de la taille des logos et création de galeries à défilement horizontal (scroll-snap)[cite: 4, 10].

## 🤝 Travail en Équipe
Ce site a été conçu en groupe. Afin de gagner en efficacité tout en gardant une cohérence visuelle globale, nous nous sommes réparti l'intégration des pages détaillées :
* **Page Colisée** (Rubrique Lieux)[cite: 5].
* **Page Joconde** (Rubrique Œuvres)[cite: 7].
* **Page Jules César** (Rubrique Personnages)[cite: 9].
